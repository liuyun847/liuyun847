## DSH 插件

DeepSeek Harness(DSH)的宿主插件与 Web 客户端插件。

| 仓库 | 说明 |
|---|---|
| [dsh-llm-auto](https://github.com/liuyun847/dsh-llm-auto) | 宿主插件：注册 auto 模型，按有序回退链在多条 provider+model 间静默切换 |
| [dsh-host-restart](https://github.com/liuyun847/dsh-host-restart) | 宿主插件：提供 restart_dsh 工具，重启后自动恢复原会话续跑 |
| [dsh-host-compliance-check](https://github.com/liuyun847/dsh-host-compliance-check) | 宿主插件：轮末自动派发需求合规检查子智能体 |
| [dsh-client-ui-session-rail](https://github.com/liuyun847/dsh-client-ui-session-rail) | 客户端插件：侧边栏收起时在左侧空白区竖排显示活跃会话横条 |
| [dsh-client-ui-peak-valley](https://github.com/liuyun847/dsh-client-ui-peak-valley) | 客户端插件：模型选择按钮左侧显示 DeepSeek API 峰/谷价状态（绿=谷，橙=峰） |
| [dsh-client-ui-turn-chime](https://github.com/liuyun847/dsh-client-ui-turn-chime) | 客户端插件：AI 回复完成时播放双音提示音 |
